## PRD Template

When creating a new PRD, use this structure:

```markdown
# [Feature Name] PRD

**Status**: Draft | In Review | Approved | In Development | Completed
**Owner**: [Name]
**Created**: [Date]
**Last Updated**: [Date]

## 1. Overview

Brief description of the feature and why it's needed.

## 2. Goals & Success Metrics

- Goal 1
- Goal 2
- Key metrics to track

## 3. User Stories

- As a [user type], I want [goal] so that [benefit]

## 4. Requirements

### Functional Requirements
- Requirement 1
- Requirement 2

### Non-Functional Requirements
- Performance requirements
- Security requirements
- Scalability requirements

## 5. Design & User Experience

UI/UX considerations, mockups, user flows

## 6. Technical Considerations

Implementation approach, dependencies, tech stack

## 7. Timeline & Milestones

- Phase 1: [Date]
- Phase 2: [Date]

## 8. Open Questions

- Question 1?
- Question 2?
```
