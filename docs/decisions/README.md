## ADR Template

When documenting a decision, use this format:

```markdown
# ADR-[NUMBER]: [Title]

**Date**: [YYYY-MM-DD]
**Status**: Proposed | Accepted | Deprecated | Superseded
**Deciders**: [Names]

## Context

What is the issue we're trying to solve? What are the constraints?

## Decision

What did we decide to do and why?

## Alternatives Considered

1. **Alternative 1**
   - Pros: ...
   - Cons: ...

2. **Alternative 2**
   - Pros: ...
   - Cons: ...

## Consequences

### Positive
- Benefit 1
- Benefit 2

### Negative
- Trade-off 1
- Trade-off 2

### Neutral
- Other implications

## References

- Links to related discussions, PRDs, or documentation
```

## Numbering

ADRs are numbered sequentially: ADR-001, ADR-002, etc.

## Status Definitions

- **Proposed**: Under discussion
- **Accepted**: Approved and being implemented
- **Deprecated**: No longer relevant
- **Superseded**: Replaced by a newer ADR (link to the new one)
